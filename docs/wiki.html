Find a state

  1. Open the evidence gallery and expand Search and filter evidence.
  2. Choose a category, appearance, language mode, or viewport. These controls filter the gallery cards and the provenance register.
  3. Use plain text search for a state name or caption. The count reports how many evidence records remain visible.
  4. Clear filters to return to the full collection. The search, selected filters, collapsed state, and appearance preference are stored only in this browser.

Examples below change the gallery URL and apply filters to the published evidence collection. They do not execute or verify the source application.

Read an evidence record

Each card links to its original PNG. Open Capture details and limits for the source revision, source image digest, output dimensions, viewport, timestamp basis, and image hash. A timestamp without a timezone is labeled as such. An unavailable timestamp stays unavailable.

Read the visible limitation before drawing a conclusion. A screenshot captures pixels from one recorded state. Separate interaction receipts support the checks named on this page, and any failed or unverified result remains visible in the evidence notes.

The provenance register shows the same inventory in a searchable table. The source repository remains private; the public records include source hashes but no private repository URL or machine-local path.
